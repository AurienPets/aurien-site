# aurien-site

Site institucional da **AURIEN TECNOLOGIA** (L. R. DE OLIVEIRA SANTOS
TECNOLOGIA, CNPJ 32.896.287/0001-76).

Publicado por GitHub Pages.

## Conteúdo

- Página inicial, com a apresentação da empresa e dos aplicativos.
- `/privacidade/validi/` — Política de Privacidade do Validi.
- `/termos/validi/` — Termos de Uso do Validi.
- `/privacidade/aurien-pets/` — Política de Privacidade do Aurien Pets
  (conteúdo ainda em elaboração).

As páginas legais são geradas a partir dos documentos em Markdown mantidos no
projeto do site; o texto não é editado no HTML.

HTML, CSS e um script curto. Sem framework e sem processo de build.
